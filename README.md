# Student-Record-Management-System
A simple command-line based Student Record Management System built using Python.

This project helps users manage student records using CRUD operations. Student data is stored in a CSV file.

## Features

- Add a new student record
- View all student records
- Search a student by ID
- Update student details
- Delete a student record
- Store student data in a CSV file
- Validate user input
- Prevent duplicate student IDs
- Menu driven program

## CRUD Operations

CRUD means:

- Create — Add a new student record
- Read — View all records or search for a student
- Update — Change an existing student record
- Delete — Remove a student record

## Input Validation

The program checks for:

- Empty student name
- Duplicate student ID
- Invalid age
- Invalid marks
- Marks outside the range of 0 to 100
- Invalid menu choice
